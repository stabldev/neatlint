neatlint

Set up ESLint and Prettier for your JavaScript and TypeScript projects. One command, zero config conflicts.

$ npx neatlint init
npm GitHub

Usage

npx neatlint init
pnpm dlx neatlint init
bunx neatlint init
yarn dlx neatlint init

Default configuration

.prettierrc
{
  "semi": true,
  "singleQuote": false,
  "trailingComma": "es5"
}
eslint.config.js (patched)
import prettier from "eslint-config-prettier";
// ... your existing config

export default [
  // ...existing rules,
  prettier,
];
