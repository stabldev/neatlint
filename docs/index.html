neatlint

Set up ESLint and Prettier for your JavaScript and TypeScript projects. One command, zero config conflicts.

$ npx neatlint init
npm GitHub

What it does

  1. Runs ESLint initialization
    Invokes the interactive ESLint setup tool appropriate for your package manager to create an ESLint configuration.
  2. Installs dependencies
    Adds prettier and eslint-config-prettier as dev dependencies.
  3. Generates .prettierrc
    Creates a .prettierrc with sensible defaults.
  4. Patches ESLint flat config
    Locates your ESLint config file and integrates eslint-config-prettier to prevent formatting rule conflicts.
  5. Configures package.json scripts
    Adds lint, format, and format:check scripts to your package.json.

Usage

npx neatlint init
pnpm dlx neatlint init
bunx neatlint init
yarn dlx neatlint init

Default configuration

.prettierrc
{
  "semi": true,
  "singleQuote": false,
  "trailingComma": "es5"
}
eslint.config.js (patched)
import prettier from "eslint-config-prettier";
// ... your existing config

export default [
  // ...existing rules,
  prettier,
];
